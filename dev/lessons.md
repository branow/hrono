# hrono project lessons (read by every autodev agent; retro appends)
- dev, prompts: when a shipped prompt default changes, add every earlier shipped default hash to the upgrade list and test an old row is replaced while an edited one is kept; E055 shipped without it and qa had to add 10 hashes (e4dc224).
- dev, tests: for each line of prompt or wiring a feature depends on, remove it and see a test fail; E055 qa found the "areas" line for level 2+ could be deleted with the suite green (68b66e4).
- dev, ui, i18n: every new setting label, tooltip or form field gets its Ukrainian string in the same commit, and a cost or price line states its basis for metered and subscription providers; E057 qa had to add the Ukrainian tooltips (88fd21d) and a subscription-estimate test (babab38), E055 and E057 followups both caught copy that only held for the metered setup.
- dev, forms: a setup/settings form that is refused and re-rendered must keep a field the user cleared, not refill the default; test the refusal path with a cleared field (E057 f455a74 found by qa).
- dev, tests: when a stage re-runs over an already-processed node (re-brief, re-cluster, settle), test the case where a lower pass changes the input of a node that already holds an extension; E058 qa found a reviewed root lost its extension with no new pass and the dry run miscounted (4ff1226).
- dev, llm output: parse model JSON by scanning for the first balanced object, never first-brace to last-brace; prose with braces around a paid answer lost a review (E058 b322174).
- dev, errors: a paid-call stage that is optional when unconfigured must tell "not configured" from "call failed"; a provider error is never reported as the no-model case and never lets the sync succeed on the fallback; test the failing-provider path (E056 qa 6d04627).
- po, dev: a size or ratio bound in a Done when (x times, N bytes) is measured on a real run before it is written, never guessed; E059 wrote 2.5x for the extended root page, real was 4.35x, cost a round and ruling D10 (5x).
- dev, qa: when a ticket changes a rule that an earlier epic pinned (a retention, keep or count rule), grep the tests and docs for that rule and update them in the same epic; E060 changed the cheaper-brief retention and only E059's six-passes test, on main after the branch started, failed at merge (round 2, 1d65132, cbec433).
- qa, dev: before the first sync or build on a copy of a real tree, point every text model (brief, judge, condense) at the fake provider; a sync on a copy with live models spent 34 real claude-code calls, over the 10-call pilot limit (E061 qa; D2).
- dev, branch: a ticket commit must not carry the epic file board move (todo -> in-dev); the board side stays main's, or the merge leaves a stale copy (E061 followups).
- dev, docs: a README or docs step that tells an admin to do something names a supported CLI/UI command (not an endpoint docs/api.md marks debug-only), and a quoted price is copied from the real dry run output; E062 README sent admins to POST /jobs settle and said $2.50 where the dry run said $2.82 (qa followups).
