How to read this map

  • Size is how much it holds A bigger circle means more chunks (or more topics) underneath it.
  • Amber needs a new brief Its summary is missing or no longer matches its contents, so recall cannot answer from it.
  • The triangle opens a topic Topics with something beneath them carry one. It points right when closed, down when open.
  • The name opens the topic page Its brief, the chunks it holds, and — if you are an admin — the controls to correct it.

What these three lines mean
  • — — pull — a chunk in the wrong home Drawn from the topic a chunk sits in to the topic it is actually closer to.
  • · · · proximity — two topics that overlap Siblings similar enough that merging them into one would be defensible.
  • ——— propagation — where a change travelled A chunk changed here, and the brief above it had to be rewritten too.

pull and proximity compare chunks, so they are only ever drawn between topics that hold chunks — open the tree down to those before turning them on.
