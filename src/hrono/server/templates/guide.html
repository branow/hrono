  • {{ _("a file you renamed or moved") }} {{ _("Its section keeps its topic: the content is the same, so nothing is compared again.") }}

{{ _("Questions") }}

{{ _("If it repairs itself, why can I edit anything by hand?") }}

{{ (_('Because grouping has no opinion about what matters to you. It can tell that two topics are similar; it cannot know that one of them is the thing your team calls "billing" and deserves its own name. A hand edit is {pinned}, which is what stops the next sync from undoing it — a correction that silently reverts is worse than no correction.')|e).format(pinned=pinned) }}

{{ _("I changed one file. How much gets rewritten?") }}

{% set touched %}{{ _("what a change touched") }}{% endset %}

{{ (_("Its own topic's brief, always. Then the judge model is asked once about that topic, by {panel} with the majority deciding, whether the new content changes what its brief says. If the answer is no, nothing above it is touched, which is what happens to a typo. If it is yes, every brief above it is marked for a rewrite, {climb}, or to the root if that is nearer. The {touched} overlay and the Activity page both show how far it went.")|e).format(panel=n_(rule.panel, "a panel of {n}", "a panel of {n}"), climb=n_(rule.climb, "up to {n} level", "up to {n} levels"), touched=touched) }}

{{ _("Why is my brief a question back to me instead of a summary?") }}

{{ _("A model was called in a context that made it answer the caller rather than summarise the material. Rewrite it by hand on the topic page — that pins it — or fix the cause and re-run. A reply that does not look like a brief is stored with a flag rather than dropped, because a flagged brief you can see beats a topic missing from the map.") }}

{{ _("Nothing happened when I re-ran a sync.") }}

{{ _("That is the design working. Condensations are keyed by content hash and briefs by their members' signature, so a re-run over unchanged sources makes no model calls. The exception is a stored reply that was not a real condensation or brief: those are tried again. If you expected work, check that the source actually fetched new commits on the Runs page.") }}
