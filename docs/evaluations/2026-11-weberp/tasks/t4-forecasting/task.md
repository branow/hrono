# Task: demand forecasting for webERP

You are a developer on webERP. Implement the demand forecasting module
described in `task/brd.md`: a new Forecasting module in the main menu with
the pages, data and processing it describes, integrated with the rest of
webERP the way this project ships features (database changes for new and
existing installations, menus, page security, user access, translations).

Deliver the change as files in the repository. When done, write `NOTES.md`
at the repository root: what you built, the objects and pages, where the
forecast gets its sales history and how it reaches MRP, and anything in the
BRD you found ambiguous and how you resolved it.
