# Task: notes on stock items

When implementing webERP and importing data from another system, ad hoc
item "notes" are often available and worth keeping. webERP has no item
notes feature; today people put such text in the item's long description.

Add the option to store zero to many notes about a stock item: a way to
add, view, edit and delete an item's notes, reachable from the item's page,
and a way to bring notes in when items are imported.


The webERP repository is in the current directory; the task is task/task.md. There is nothing to run against: deliver the change as files.
