# Parent brief: SchemaSpy 6.0.0 documentation site and its front-end assets

## What this is
The notes cover one static documentation site generated by **SchemaSpy 6.0.0** (generated Thu Jun 06 08:36 PDT 2019). It documents a PostgreSQL 11.2 database (titled "postgres Database" or "auth Database") with a `public` schema. The schema has 14 tables, 0 views, 71 columns, 16 constraints, 1 anomaly and 0 routines. The domain is payments, fees, orgs and auth/affiliation. The site uses the AdminLTE 2.x template on Bootstrap 3.3.5 with legacy bower assets. The notes also include the web-font assets (SIL OFL v1.1 license and `@font-face` rules).

Most children are near-duplicate condensations of the same generated pages. The same head, navbar, footer and script block recur, and only the page title or a local script name changes.

## Shared page scaffold (identical on every page)
- **Head:**
  - Meta: UTF-8, IE=edge, responsive viewport (`maximum-scale=1, user-scalable=no`), favicon `../favicon.png`.
  - CSS: Bootstrap 3.3.5, Font Awesome, Ionicons, DataTables (with buttons), CodeMirror, AdminLTE with `_all-skins`, Salvattore, `schemaSpy.css`.
  - Fonts: Indie Flower and Source Sans Pro.
  - IE8 shims: html5shiv and Respond.js in a conditional comment.
  - Paths: relative `../bower/...`.
- **Body class:** `hold-transition skin-blue layout-top-nav` (top navigation, no sidebar).
- **Navbar:** `navbar-static-top`, brand linking to `../index.html`, and a `#navbar-collapse` mobile toggle. The links are Tables, Columns, Constraints, Relationships, Orphan Tables, Anomalies and Routines, all relative (`../`).
- **Footer:** right-aligned `pull-right`, hidden on mobile. It has GitHub (`fa-github-square`) and StackOverflow (`fa-stack-overflow`) icon links at 2x size, plus "Generated by SchemaSpy 6.0.0" with `fa-database`.
- **Scripts:**
  - Libraries: jQuery 2.2.3, jQuery UI, Bootstrap, DataTables (with buttons for HTML5, print and colVis), SheetJS xlsx, pdfmake with `vfs_fonts`, SlimScroll, FastClick, Salvattore, AnchorJS, CodeMirror with SQL mode, and the AdminLTE app.
  - Local scripts: one page-specific script (`table.js`, `column.js`, `constraint.js`, `main.js` or `routines.js`), then `schemaSpy.js` last.
- **Page-specific JS:**
  - Type-filter DataTables (All, Tables, Views, Functions, Procedures) with a `filterBy(type)` function and a `columnsToggle`.
  - `dataTableExportButtons`: copy, Excel, CSV and PDF.
  - Navbar active-link highlighting.
  - Anchors on h3 headings.
  - A read-only CodeMirror SQL view.
  - Draggable diagram images.

## Cautions
**Legacy stack and fragile paths**
- Bootstrap 3.3.5, AdminLTE 2.x, jQuery 2.2.3 and Salvattore are end-of-life.
- Bower has been deprecated since about 2017, and its dependencies are unpinned and have no integrity hashes.
- The relative `../bower/` paths only work at the expected directory depth. The navbar's `../` links assume the page sits one level below the site root.
- Some paths are Windows-style (`.\schemaspy/images/`).
- The IE8 shims (html5shiv, Respond.js) are dead code. Respond.js doesn't work over `file://`.
- `_all-skins` loads every skin when only one is used.
- pdfmake needs `vfs_fonts.js` loaded separately.

**Page markup and accessibility**
- `user-scalable=no` and `maximum-scale=1` block zoom (one summary contradicts this).
- Several head excerpts are truncated: `</head>` or the body is missing.
- The "ADD THE CLASS layout-top-nav" comment is confusing, because the class is already applied.
- The fixed-width `.container` navbar may break on mobile.
- An empty `<script src="">` on the index page 404s silently.
- Invalid or deprecated markup:
  - `</br>`
  - `<br>` inside an h1
  - `align='left'`
  - duplicate `id="un_indexed_tables"`
  - `id="navbar-collapse"` must match the toggle's `data-target`
- Image maps use hardcoded pixel coords. They break when diagrams are regenerated or resized, and they lack alt text.
- The database name "postgres" is hardcoded, so the output is a static template and the near-duplicate pages should share one template.

**JavaScript bugs**
- Filters use hardcoded column indexes (`data[1]`, `[5]`).
- Filter clearing mixes the old `afnFiltering` API with `ext.search`.
- `activeObject` state is fragile, and the `routine_table` "All" button never sets it.
- `constraint_table` has no guard for a missing `config.pagination`.
- The navbar `== ''` check can highlight several links at once.
- `standard_table` is created with `buttons: []` while code appends a button container.
- CodeMirror `lineNumbers` is set twice.
- `eval()` is used for `.draggable()`.
- The `$.fn.digits` regex is broken: it replaces each match with a literal `"1 "` and never writes the result back.

**Schema and display quirks**
- Every FK is Restrict delete, so there is no cascading. Parents can't be deleted while children exist, even when a child's FK is null.
- `payment_type.code` has both a PK and a redundant unique constraint.
- Varchar PKs may slow joins at scale.
- `affiliation_business.business_id` depends on `business_id_seq`.
- Displayed values mislead:
  - Defaults show the string `'null'` rather than SQL NULL, even on NOT NULL PKs and FKs.
  - Nullable timestamps display as "√".
  - float8 shows size "17,17".
  - Timestamps show "29,6".
  - Some tables show "1 rows" against 2 columns.
  - `payment_method` shows a duplicated address field that doesn't match its columns.
- Verify against the real schema, not the rendered page.
- 0 views and 0 routines may mean the schema is read-only or that introspection was incomplete.
- Diagrams are PNG on some pages and SVG on others.

**Fonts**
- The `#iefix` fragment on the eot URL is required for IE6–8, and the duplicate eot entry is intentional.
- BCSans-Bold is declared `font-weight: normal`. Use `700` to get real bold.
- Only standalone sale of the fonts is restricted. Embedding is explicitly allowed.
