A packaging and deployment shell for the entity-pay NATS/STAN queue worker, run as `python /opt/app-root/pay_filer.py`. The notes cover only build, config and dependency files. The handler `pay_filer.py` and the `src/entity_pay` sources that process payment messages are not in the notes, so the handling logic is not described here.
